
═══════════════════════════════════════════════════════════════
方案 B：使用代理推送（如果有）
═══════════════════════════════════════════════════════════════

如果你有代理，设置 Git 代理：

```bash
# HTTP 代理
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890

# 推送
cd ~/Desktop/work_zone/accounting-app
git push

# 推送成功后取消代理
git config --global --unset http.proxy
git config --global --unset https.proxy
```

═══════════════════════════════════════════════════════════════
方案 E：切换到 SSH 方式推送
═══════════════════════════════════════════════════════════════

如果 HTTPS 被拦截，尝试 SSH：

```bash
cd ~/Desktop/work_zone/accounting-app

# 切换远程地址为 SSH
git remote set-url origin git@github.com:acoolper/accounting-app.git

# 推送
git push

# 如果 SSH 也失败，切回 HTTPS
git remote set-url origin https://github.com/acoolper/accounting-app.git
```

SSH 需要先配置密钥：
https://docs.github.com/en/authentication/connecting-to-github-with-ssh
